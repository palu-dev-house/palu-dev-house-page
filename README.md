# Palu Dev House

Landing page for Palu Dev House — Indonesian software house. Next.js 15 (Pages Router) + Tailwind + Framer Motion.

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production

```bash
npm run build
npm start
```

## Tests

```bash
npm test
```

Covers recommendation quiz logic.

## Deployment

Hosted on Vercel. Push to `main` → auto-deploy. Sitemap regenerates on every build. Cache-Control headers set in `next.config.js` + `public/robots.txt` generated by `next-sitemap`.

Contact details live in one place: `lib/contact.ts` (`WHATSAPP_NUMBER`, `WHATSAPP_DISPLAY`, `whatsappLink()`). Never hardcode the number in a component.

## Pricing

The site does not publish prices. Package contents live in `lib/packages.ts` and every CTA leads to WhatsApp, where the quote is worked out per project. `/harga` is permanently redirected to `/#kontak` in `next.config.js` — it was indexed, so the route must keep answering. Third-party vendor costs in `lib/articles.ts` (hosting providers, domain registrars, SaaS ERPs) are editorial content about other companies and are intentionally kept.
